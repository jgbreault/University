### Capstone

Industry capstone with **Green Metrics Technology** — an automated GIS pipeline to determine laneway house feasibility parcel-by-parcel across municipalities, using zoning bylaw extraction via LLM, deterministic rule verification, and spatial analysis in Python/QGIS.
