# Week 2

## Summary

Focused on analyzing and standardizing laneway home bylaws across Vancouver, Surrey, and Burnaby, with particular emphasis on rule extraction, rule categorization, and designing a scalable rule structure for edge cases and municipality differences.

## Tasks

- Refined and validated Vancouver laneway home rules using the shared schema
- Compared Vancouver rules against Surrey and Burnaby to identify:
  - common rules
  - municipality-specific rules
  - missing / N/A cases
- Investigated zoning edge cases including:
  - heritage-related rules
  - discretionary approvals
  - between/min/max rule structures
  - multi-building separation rules
  - parking and transit-related exceptions
- Researched how Vancouver R1-1 laneway home regulations are structured in official bylaws
- Discussed with teammates approaches for:
  - generic rule keys
  - Min / Max / Between rule representation
  - scalable schema design
  - handling future rule types and exceptions
- Helped onboard Zihao by explaining the team’s current progress and rule organization

## Time

- Vancouver bylaw analysis and rule extraction: 16 hours
- Rule comparison and validation across cities: 7 hours
- Team meetings and schema discussions: 5 hours
- Research on edge cases and bylaw interpretation: 4 hours

**Total: 32 hours**

## Challenges

- Different municipalities express similar zoning rules in different formats and terminology
- Some bylaws contain implicit conditions that are difficult to standardize directly
- Determining whether “Between” rules should be represented as:
  - separate Min/Max rules
  - or a combined rule structure
- Handling exceptions, discretionary approvals, and heritage-related overrides within a consistent schema
- Identifying which rules are generalizable across cities versus municipality-specific

## Next Steps

- Finalize the shared rule structure and edge-case handling approach
- Begin preparing presentation slides for the project update
- Further investigate multi-building and separation-related rules
- Continue validating rule consistency across Vancouver, Surrey, and Burnaby
