### Undergrad_Physics_UW

University of Waterloo undergraduate physics program: co-op work terms
(Perimeter Institute, SNOLAB) and course projects (e.g. Star_Simulator, a
numerical stellar-structure simulator).

- `Co-ops/Perimeter_Institute/` — fast radio burst detection tooling; see
  [Co-ops/Perimeter_Institute/README.md](Undergrad_Physics_UW/Co-ops/Perimeter_Institute/README.md)
- `Co-ops/SNOLAB/` — reports and presentation from the SNOLAB work term
- `Projects/Star_Simulator/` — stellar structure simulator solving the 5
  coupled stellar-structure differential equations via 4th-order Runge-Kutta;
  see [Projects/Star_Simulator/README.md](Undergrad_Physics_UW/Projects/Star_Simulator/README.md)
- `Projects/Research_Project/` — research project reports, presentations, and
  referenced papers
- `UW_grades.pdf` — transcript
